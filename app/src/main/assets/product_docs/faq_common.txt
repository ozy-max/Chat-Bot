=== ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ (FAQ) ===

Q: Почему не работает авторизация?
A: Проблемы с авторизацией могут возникать по нескольким причинам:
1. Проверьте интернет-соединение - приложению нужен доступ к сети
2. Убедитесь что API ключи настроены корректно в настройках
3. Проверьте что Ollama сервер запущен (если используете локальную LLM)
4. Очистите кэш приложения через Настройки -> Приложения -> ChatBot -> Очистить кэш
5. Перезапустите приложение
Если проблема сохраняется, обратитесь в службу поддержки с номером вашего тикета.

Q: Как настроить API ключи?
A: Настройка API ключей:
1. Откройте меню настроек (иконка шестеренки)
2. Выберите "API Configuration"
3. Введите ваш YandexGPT API ключ и Folder ID
4. Или введите Claude API ключ (начинается с sk-ant-api03-)
5. Нажмите "Сохранить"
6. Перезапустите приложение для применения изменений

Q: Почему RAG не находит документы?
A: Возможные причины:
1. Документы еще не проиндексированы - используйте команду /index для индексации
2. Ollama сервер не запущен - проверьте статус через команду /status
3. Модель embeddings не загружена - убедитесь что nomic-embed-text установлена
4. Путь к документам неверный - проверьте настройки
Используйте команду /project_index для переиндексации документации.

Q: Как работает команда /help?
A: Команда /help предоставляет помощь по работе с приложением:
- /help - показывает список всех доступных команд
- /help <тема> - поиск информации по конкретной теме в документации
Например: /help api или /help rag

Q: Что делать если приложение зависает?
A: Действия при зависании:
1. Подождите 30 секунд - возможно идет обработка большого запроса
2. Проверьте логи через команду /status
3. Закройте и перезапустите приложение
4. Очистите кэш и данные приложения
5. Убедитесь что у вас достаточно свободной памяти (минимум 500 MB)
Если проблема повторяется, создайте тикет в поддержке с описанием действий.

Q: Как создать тикет в поддержку?
A: Создание тикета поддержки:
1. Используйте команду /support <ваш вопрос>
2. Система автоматически создаст тикет и привяжет его к вашему аккаунту
3. Вы получите номер тикета для отслеживания
4. Ответ придет в течение 24 часов
Пример: /support Не могу подключиться к Ollama серверу

Q: Какие модели LLM поддерживаются?
A: Поддерживаемые модели:
- Ollama: llama3, mistral, phi, qwen и другие
- YandexGPT: yandexgpt/latest
- Claude: claude-3-haiku, claude-3-sonnet
Для работы с Ollama моделями нужен локальный Ollama сервер.
Для API моделей нужны соответствующие ключи.

Q: Как работает Git интеграция?
A: Git интеграция через MCP позволяет:
- Проверять статус репозитория: /git status
- Искать код в проекте: /git search <паттерн>
- Получать информацию о проекте: /project_info
Git команды выполняются на хост-машине через Python MCP сервер.

Q: Почему медленно работает RAG?
A: Скорость RAG зависит от:
1. Мощности вашего устройства
2. Размера базы документов
3. Загруженности Ollama сервера
4. Качества интернет-соединения (для API)
Для ускорения:
- Используйте более мощное устройство
- Ограничьте количество индексируемых документов
- Используйте более быстрые модели (phi вместо llama3)
- Настройте параметры topK и similarity threshold

Q: Как обновить приложение?
A: Обновление приложения:
1. Проверьте наличие обновлений в Google Play Store (когда будет опубликовано)
2. Или скачайте последнюю версию APK с GitHub релизов
3. Установите обновление
4. При первом запуске может потребоваться переиндексация документов
Все ваши настройки и история чата сохранятся.
