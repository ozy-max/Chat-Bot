=== ОБЗОР ПРОДУКТА ===

Название: ChatBot AI Assistant
Версия: 1.0.0
Платформа: Android

ОПИСАНИЕ:
ChatBot AI Assistant - это интеллектуальный помощник для работы с проектами, документацией и поддержки пользователей.
Приложение использует технологии RAG (Retrieval-Augmented Generation) и MCP (Model Context Protocol) для предоставления
точных ответов на основе контекста проекта и документации.

ОСНОВНЫЕ ВОЗМОЖНОСТИ:
1. Умный чат с поддержкой контекста и истории диалогов
2. RAG-поиск по документации проекта
3. Интеграция с Git через MCP
4. Система поддержки пользователей с доступом к тикетам
5. Работа с локальными LLM через Ollama
6. Интеграция с YandexGPT и Claude API

ТЕХНИЧЕСКИЙ СТЕК:
- Kotlin + Jetpack Compose
- Ollama (локальные LLM)
- ChromaDB (векторная БД)
- MCP Server (Python + Node.js)
- OkHttp для API запросов

СИСТЕМНЫЕ ТРЕБОВАНИЯ:
- Android 8.0 (API 26) или выше
- 4 GB RAM минимум
- Интернет-соединение для API
- Ollama сервер (опционально, для локального RAG)
