=== РУКОВОДСТВО ПО УСТРАНЕНИЮ НЕПОЛАДОК ===

ПРОБЛЕМЫ С ПОДКЛЮЧЕНИЕМ:

1. Ошибка "Connection refused" при запросе к Ollama
Решение:
- Убедитесь что Ollama сервер запущен на вашей машине
- Проверьте что порт 11434 не заблокирован файерволом
- Используйте правильный адрес сервера (по умолчанию http://localhost:11434)
- На эмуляторе используйте 10.0.2.2 вместо localhost
- На реальном устройстве используйте IP адрес компьютера в локальной сети

2. Ошибка "Timeout" при API запросах
Решение:
- Проверьте стабильность интернет-соединения
- Увеличьте timeout в настройках (Settings -> Advanced -> Timeout)
- Попробуйте другую сеть (переключитесь с Wi-Fi на мобильные данные)
- Убедитесь что API сервер доступен (проверьте статус сервиса)

3. Ошибка "Unauthorized" или "Invalid API Key"
Решение:
- Проверьте правильность API ключа
- Убедитесь что ключ не истек
- Проверьте что у ключа есть необходимые права доступа
- Для YandexGPT проверьте Folder ID
- Пересоздайте API ключ если необходимо


ПРОБЛЕМЫ С RAG:

1. RAG не находит релевантные документы
Решение:
- Проверьте что документы проиндексированы: /project_index
- Увеличьте topK параметр для поиска большего количества документов
- Уменьшите similarity threshold для более мягкого фильтра
- Используйте более точные запросы
- Переформулируйте вопрос

2. RAG возвращает неправильную информацию
Решение:
- Обновите документацию и переиндексируйте
- Проверьте качество embeddings модели
- Убедитесь что используется правильная модель (nomic-embed-text)
- Очистите векторную БД и проиндексируйте заново

3. Ошибка "Embedding model not found"
Решение:
- Установите модель: ollama pull nomic-embed-text
- Проверьте что модель загружена: ollama list
- Перезапустите Ollama сервер
- Проверьте достаточно ли места на диске


ПРОБЛЕМЫ С MCP:

1. MCP команды не работают
Решение:
- Проверьте что Python MCP сервер запущен
- Убедитесь что порт 3000 не занят другим приложением
- Проверьте логи MCP сервера: ~/FlutterProjects/ChatBot/mcp-server/server.log
- Перезапустите MCP сервер: cd mcp-server && python3 server.py

2. Git команды возвращают ошибки
Решение:
- Убедитесь что вы находитесь в Git репозитории
- Проверьте что Git установлен на хост-машине
- Проверьте права доступа к репозиторию
- Убедитесь что путь к проекту правильный в ProjectDocsService


ПРОБЛЕМЫ С ПРОИЗВОДИТЕЛЬНОСТЬЮ:

1. Медленная работа приложения
Решение:
- Закройте другие приложения для освобождения RAM
- Очистите кэш приложения
- Уменьшите размер контекста (Context Size в настройках)
- Используйте более легкую модель LLM
- Обновите устройство или используйте более мощное

2. Приложение вылетает при больших запросах
Решение:
- Уменьшите размер запроса
- Разбейте большой запрос на несколько маленьких
- Увеличьте память для приложения в настройках Android
- Закройте фоновые приложения


ПРОБЛЕМЫ С ДАННЫМИ:

1. История чата не сохраняется
Решение:
- Проверьте разрешения приложения на запись
- Убедитесь что достаточно места на устройстве
- Проверьте настройки резервного копирования
- Не удаляйте данные приложения вручную

2. Настройки сбрасываются после перезапуска
Решение:
- Убедитесь что приложение не в режиме экономии памяти
- Проверьте что батарейная оптимизация отключена для приложения
- Не используйте "Force Stop" для закрытия приложения
- Проверьте права доступа к хранилищу


ОБЩИЕ РЕКОМЕНДАЦИИ:

Для диагностики проблем:
1. Используйте команду /status для проверки состояния системы
2. Проверьте логи приложения через Android Studio Logcat
3. Запишите последовательность действий, приводящих к ошибке
4. Сделайте скриншот сообщения об ошибке
5. Создайте тикет в поддержку с подробным описанием

Перед обращением в поддержку:
- Попробуйте перезапустить приложение
- Проверьте что у вас последняя версия
- Убедитесь что проблема воспроизводится стабильно
- Подготовьте информацию о вашем устройстве и версии Android

Контакты поддержки:
- В приложении: команда /support <описание проблемы>
- Email: support@chatbot-ai.example.com
- GitHub Issues: https://github.com/ozy-max/ChatBot/issues
